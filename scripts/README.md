# Scripts

Run commands from the repository root with Bun installed. Install the project's dependencies with `bun install` before using these scripts.

| Script                                                           | Usage guide                                                    | Package command           |
| ---------------------------------------------------------------- | -------------------------------------------------------------- | ------------------------- |
| [`firebase/set-custom-claims.ts`](firebase/set-custom-claims.ts) | [Update Firebase custom claims](firebase/set-custom-claims.md) | `bun run firebase:claims` |
| [`codegen/tab.ts`](codegen/tab.ts)                       | [List, add, or delete UI tabs](codegen/tab.md)                   | `bun run tab`      |

Each guide includes prerequisites, arguments, examples, and the changes the script makes.
